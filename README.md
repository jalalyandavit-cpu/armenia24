# Armenia24

Армяноязычный адаптивный новостной портал. Только демонстрационные материалы, явно обозначенные как примеры.

## Запуск

Нужен Python 3.10+; сторонние зависимости не требуются. Node/npm необязательны.

```sh
cd armenia24
python3 scripts/build.py
python3 scripts/check.py
python3 scripts/serve.py
```

Откройте **http://localhost:4173**. Остановить: Ctrl+C. После изменения исходников перезапустите сервер. Аналоги через npm: `npm run build`, `npm test`, `npm run dev`.

## Что реализовано

Главная с крупным визуалом и последними материалами; 6 тематических разделов; 8 отдельных статей; поиск по заголовкам и описаниям; мобильное меню; страница 404. HTML формируется при сборке, поэтому текст доступен без JavaScript. JS нужен только для поиска и мобильного меню. Локальные армянские шрифты, WebP, отложенная загрузка второстепенных изображений, семантическая разметка, метаданные и Open Graph. Внешних запросов при просмотре нет.

Демоверсия сознательно использует `noindex,nofollow` и запрет в `robots.txt`. Перед реальной публикацией заменить примеры проверенными материалами, включить индексирование, задать домен, canonical и sitemap. Не добавлены вымышленные даты, курсы валют, погода, просмотры или события. Время в демоленте служит только примером оформления и не является временем реальной публикации.

## Структура и будущая редакторская панель

- `content/articles.json` — единый источник контента.
- `scripts/build.py` — загрузка данных и HTML-шаблоны; отделены от оформления.
- `public/` — CSS, JS, шрифты и изображения.
- `dist/` — результат сборки (не хранится в Git).
- `docs/editorial.md` — модель контента и план подключения CMS.

Сейчас административная панель и сервер загрузки файлов **не реализованы**. Редактор может менять JSON и пересобирать сайт. Видеостраница явно показывает, что файл ещё не добавлен.

## Изображение и шрифты

`public/assets/yerevan.webp` — изображение, сгенерированное ИИ для этой демонстрации, не документальная фотография и не свидетельство события. На странице оно обозначено как иллюстрация. Остальные превью — абстрактная графика CSS. DejaVu Sans поддерживает армянский и поставляется локально; лицензия в `public/assets/FONT-LICENSE.txt`.

## Проверки

`python3 scripts/check.py` проверяет ссылки всех страниц, изображения, языковую разметку и обозначение демоматериалов. Для будущей CMS необходимы отдельные интеграционные проверки аутентификации, прав и загрузки медиа.

## GitHub Pages

Адрес проекта: https://jalalyandavit-cpu.github.io/armenia24/

В корне репозитория хранится готовый статический сайт: `index.html`, `404.html`, `style.css`, `app.js`, `assets/`, `news/`, `section/`, `search/`, `data.json` и `.nojekyll`. Python на хостинге не требуется. Исходники остаются в `public/`, `content/` и `scripts/`.

Источник в **Settings → Pages → Build and deployment**: **Deploy from a branch → main → / (root)**. Не выбирать `dist/`: этот каталог предназначен для локальной сборки и исключён из Git.

После изменения контента или исходников обновить готовые файлы:

```sh
python3 scripts/export_pages.py
python3 scripts/check.py .
```

Сборка Pages добавляет `/armenia24/` ко всем внутренним HTML-ссылкам и изображениям. Поиск получает базовый путь из метатега `site-base`; URL данных и результатов работают и на вложенных страницах. CSS использует относительные пути к шрифтам. `.nojekyll` отключает обработку готовых файлов через Jekyll.

Обычная команда `python3 scripts/build.py` по-прежнему создаёт сайт в `dist/` для локального корня `/`. Для произвольного подпути поддерживается переменная `BASE_PATH`.

Демометки и запрет индексации сохранены. Административная панель не добавлена.
